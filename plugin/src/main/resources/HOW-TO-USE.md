
This plugin can only be run within a Minecraft server environment (Paper/Spigot/Bukkit).

How to run it on a server:

  1) Download a compatible server jar:
     - Paper: https://papermc.io/downloads
     - Spigot: https://getbukkit.org/download/spigot
     - Bukkit: https://getbukkit.org/download/craftbukkit
  2) Create a server folder and place the downloaded jar inside it.
  3) Start the server once to generate the directory structure, then stop it.
  4) Place this plugin's .jar file into the 'plugins' folder.
  5) Start the server again.
  6) Watch the console for the plugin's startup message and fix any reported errors.
  7) Configure permissions (via your permissions plugin or ops.json).
  8) Restart the server to apply changes.
